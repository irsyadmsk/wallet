# Bundled owner typography

22 October 2026. Playfair Display 600 and Plus Jakarta Sans 400/600 copied from the already downloaded official Google Fonts files in irsyads/ops/owner-plan/fonts. Libre Baskerville 400 normal/italic downloaded from official fonts.googleapis.com/stylesheets and fonts.gstatic.com binaries. Fonts unmodified; family registration in pubspec.yaml. OFL texts for all three families included here. Runtime uses the bundled files, not GoogleFonts fetches. Adding font assets changes native-update compatibility and is not assumed to fit an existing OTA base.
