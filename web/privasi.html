Kebijakan Privasi Wallet

Berlaku sejak 28 September 2026 · Aplikasi Android com.irsyads.wallet dan wallet.irsyads.com

Wallet adalah buku kas pribadi dan keluarga buatan Muhammad Irsyad Sirojul Khoeir. Halaman ini menjelaskan data apa yang disimpan, untuk apa, dan bagaimana Anda menghapusnya.

Tanpa akun atau dengan akun

Wallet bisa dipakai tanpa akun. Selama Anda belum masuk, semua catatan keuangan hanya tersimpan di perangkat Anda (di web: di browser Anda) dan tidak dikirim ke server kami. Akibatnya, catatan itu hilang bila aplikasi dihapus atau data browser dibersihkan.

Bila Anda masuk atau mendaftar, catatan di perangkat ikut dipindahkan ke akun Anda, lalu data di bawah ini disimpan di server agar tercadang, bisa dibuka di perangkat lain, dan bisa dipakai bersama keluarga.

Yang tetap di perangkat Anda

  • Foto struk dan hasil pindai teks (OCR) diproses di perangkat dan tidak diunggah.
  • Data kartu e-money yang dibaca lewat NFC hanya dipakai untuk mengisi saldo akun yang Anda buat.
  • PIN kunci aplikasi dan preferensi tampilan (termasuk mata uang tampilan total) disimpan di perangkat saja.
  • Tanpa akun: seluruh catatan keuangan.

Penyimpanan dan keamanan

Data disimpan di Supabase (server di Singapura), dikirim melalui HTTPS, dan dilindungi aturan akses baris sehingga hanya Anda dan anggota keluarga Anda yang bisa membacanya. Salinan juga disimpan di perangkat Anda agar aplikasi tetap bisa dipakai tanpa internet.

Pihak ketiga

  • Supabase: penyimpanan dan autentikasi.
  • CoinGecko: harga kripto. Aplikasi hanya meminta harga koin; tidak ada data pribadi yang dikirim.
  • Currency API (lewat jsDelivr/Cloudflare): kurs mata uang. Hanya kurs yang diminta; tidak ada data pribadi yang dikirim.
  • Galeri24: harga emas, diambil lewat server Wallet; tidak ada data pribadi yang dikirim.
  • Shorebird (aplikasi Android): mengirim perbaikan kecil langsung ke aplikasi tanpa lewat Play Store. Untuk itu aplikasi mengirim versi aplikasi, jenis perangkat, dan pengenal perangkat acak yang tidak terhubung ke identitas atau catatan keuangan Anda.

Kami tidak menjual data, tidak menampilkan iklan, dan tidak memakai data Anda untuk pelacakan.

Menghapus data dan akun

Di aplikasi: Pengaturan › Zona bahaya.

  • Hapus semua data mengosongkan buku kas Anda di semua perangkat; akun tetap ada.
  • Hapus akun permanen menghapus akun beserta seluruh datanya dari server seketika.

Tidak bisa masuk? Lihat cara meminta penghapusan akun.
